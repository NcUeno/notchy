プライバシーポリシー

最終更新日: 2026 年 10 月 26 日

Notchy（以下「本アプリ」）は、Windows 用のデスクトップアプリです。本ポリシーは、本アプリが扱う情報と、その取り扱い方法を説明します。 本アプリには開発者が運営するサーバーはなく、ユーザーの情報を開発者が受け取ることはありません。

1. 本アプリが扱う情報

  • Google カレンダーのデータ: ユーザーが Google アカウントでログインした場合に、カレンダーの一覧と予定（タイトル、日時、場所）を読み取ります。
  • Google アカウントのメールアドレス: ログイン中のアカウントを設定画面に表示するために使います。
  • 認証情報: Google から発行されるアクセストークンとリフレッシュトークン。
  • 設定: 天気を表示する地域、表示するカレンダーの選択、ユーザーが追加した iCal URL。

2. 利用目的

取得した情報は、本アプリの画面に時計・天気・予定を表示するためだけに使います。 広告、分析、プロファイリング、機械学習の学習などには一切使いません。

3. 保存場所

  • リフレッシュトークンは、ユーザーの PC の Windows 資格情報マネージャーに保存されます。
  • アクセストークンと予定のデータは、本アプリの実行中にメモリ上でだけ保持されます。
  • 設定とメールアドレスは、ユーザーの PC 内の本アプリ用フォルダ（%APPDATA% など）に保存されます。

4. 第三者への提供

本アプリは、取得した情報を開発者を含む第三者に送信・共有・販売しません。 本アプリが通信する相手は次のサービスだけです。

  • Google（ログインとカレンダーの読み取り）
  • Open-Meteo（天気の取得）: 設定した地域の緯度・経度だけを送信します。Google のデータは送信しません。
  • ユーザーが自分で追加した iCal URL の提供元

5. Google API サービスのユーザーデータに関するポリシー

本アプリによる Google API から取得した情報の利用および他のアプリへの転送は、 Google API Services User Data Policy （Limited Use の要件を含む）に従います。

6. データの削除とアクセスの取り消し

  • 本アプリの設定画面で「ログアウト」すると、保存されたトークンを削除し、Google 側の許可も取り消します。
  • Google アカウントの サードパーティ製のアプリとサービス からも、いつでもアクセスを取り消せます。
  • 本アプリをアンインストールし、本アプリ用フォルダを削除すると、設定もすべて削除されます。

7. 本ポリシーの変更

本ポリシーを変更する場合は、このページを更新し、最終更新日を改めます。

8. お問い合わせ

本ポリシーに関するお問い合わせは、Google の同意画面に表示されるサポート用メールアドレスまでご連絡ください。
